# ابدأ من هنا — Morphix 1.4.5

هذه نسخة مصدرية كاملة **للتطوير والتجربة**. لا تحتوي ملف DMG موثقًا جاهزًا للتثبيت.

## على الماك

1. أغلق جميع نسخ Morphix السابقة تمامًا من أيقونة M في شريط القوائم وأوقف أي Terminal يشغّل `main.py`.
2. فك ضغط النسخة الكاملة في مجلد جديد مستقل. **لا تخلط ملفاتها مع إصدارات أقدم.**
3. افتح Terminal داخل مجلد `Morphix` الجديد.
4. نفّذ الأمر:

```bash
zsh ./Launch_Morphix_Mac.command
```

سيُنشئ المشروع `.venv` ويثبت Python libraries المطلوبة عند التشغيل الأول. بعدها يعمل في الخلفية.

> لا تكتب `python main.py` من بيئة `(base)` قبل تجهيز `.venv`. في هذا الإصدار، إذا كانت `.venv` موجودة فسيعيد Morphix تشغيل نفسه باستخدامها؛ وإذا لم تكن موجودة فسيعرض تعليمات واضحة بدل ظهور خطأ `No module named 'fitz'` أثناء التحويل.

## اختبار القص السريع (بدون Studio)

1. حدد صورة PNG أو JPEG في Finder.
2. اضغط `⌘ + Shift + M`، واختر `Crop & rotate`.
3. ستظهر نافذة صغيرة للصورة فيها إطار قص بمقابض، وزرّي تدوير ±90° وشريط زاوية حرة.
4. اختر `Save Copy` لحفظ `filename_edited.png` أو `Save As…` لاختيار موقع واسم آخر؛ الصورة الأصلية محفوظة.
5. افتح Morphix Studio من أيقونة M فقط لتخصيص العجلة أو تنفيذ العمليات الجماعية.

## تشخيص الأعطال

```bash
.venv/bin/python doctor_runtime.py
.venv/bin/python gui_selftest_v144.py
```

اختبار GUI يحتاج جلسة رسومية على الماك. السطر `GUI smoke test: PASS` يدل على نجاح المحرر والضغط المحاكى على العجلة؛ بعده جرّب النقر فعليًا بالماوس على سطح المكتب.

إذا فشل التطبيق، افتح السجل: `~/Library/Logs/Morphix/morphix.log`.

## دعم الأنظمة

- المصدر واحد لـmacOS وWindows، لكن بناء `.app` و `.exe` مستقل يتطلب أدوات بناء على نظامه واختبارات منفصلة.
- Office LibreOffice وRAR محركات لها شروط تضمين خاصة؛ تشغيل المصدر ليس هو نفسه تشغيل التطبيق المثبت المستقل.

## دمج PDF مع صور بالترتيب

- حدّد ملفات PDF وPNG وJPEG وWebP وغيرها من الصور المدعومة من Finder ثم استدعِ العجلة.
- سيظهر **Merge to PDF** أو **Merge + Compress** حتى عند المزج بين الصور وPDF.
- قبل بدء الدمج تظهر نافذة **Arrange merged PDF**. رتّب الملفات بالسحب والإفلات أو زرّي Move up وMove down.
- يؤخذ الترتيب من أعلى القائمة إلى أسفلها، وتُدرج **جميع صفحات PDF** في موقع الملف، بينما تتحول كل صورة إلى صفحة واحدة.
- **مهم:** Finder لا يضمن إرسال ترتيب نقر المستخدم على الملفات. Morphix يحافظ على ترتيب الإضافات التي يراقبها أثناء فتح العجلة، لكن راجع الترتيب في النافذة قبل بدء الدمج لضمان النتيجة.
- لا تُعدّل ملفاتك الأصلية، والناتج يُحفظ باسم `merged.pdf` أو اسم جديد دون الكتابة على ملف موجود.
